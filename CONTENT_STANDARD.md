# Content Standard

Voice, tone, and quality requirements for all Codokey.com content.

## Voice

**Institutional. Precise. Sovereign.**

Write as a governance reference authority — not a startup marketing team, not a security vendor sales page, not a developer blog.

## Tone Attributes

| Use | Avoid |
|-----|-------|
| Definitional language | Hype and superlatives |
| Protocol references | Product feature lists |
| Diff-style evidence | Stock photography metaphors |
| Restrained inquiry language | Urgency and scarcity tactics |
| "Reference model" | "Platform" or "solution" |
| "Governance boundary" | "Feature" or "capability" |

## Positioning Language

**Always say:**
- reference model
- charter
- protocol
- scorecard (self-assessment)
- strategic digital asset
- future-ready governance infrastructure

**Never say (unless actual product exists):**
- "Our platform"
- "Sign up"
- "Start your free trial"
- "Enterprise-ready security product"
- "Certified" or "Compliant"
- "We scan your codebase"

## Visual Content Standard

Content should feel like it belongs in:
- A diff review interface
- A protocol specification file
- An agent permission configuration
- A terminal audit output
- Reference documentation

Not in:
- A SaaS hero section with gradient backgrounds
- A pricing table
- A testimonial carousel
- A newsletter capture modal

## Page Structure

Each page follows the governance console pattern:

1. **File header** — path breadcrumb, diff stats
2. **Content body** — charter-style or diff-style content
3. **Internal links** — related reference pages
4. **Footer** — logo, meta, tag, full navigation

## Terminology Consistency

| Term | Definition |
|------|------------|
| AI Code Access Governance | Primary category name |
| code-key boundary | Separation between code access and credential access |
| agent authority surface | Total scope of what an agent can read, write, execute |
| secrets boundary | Defined exclusion zone for credential classes |
| governance debt | Accumulated risk from ungoverned agent sessions |
| audit memory | Immutable record of agent actions and scope |
| production authority | Human-gated path from code to deployment |

## Scorecard Disclaimer

Every scorecard reference must include:

> Reference self-assessment only. Not a formal certification, audit, or security assessment.

## Review Checklist

Before publishing any content:

- [ ] Positions Codokey as reference model, not product
- [ ] Uses institutional language
- [ ] Contains no broken links
- [ ] Includes internal links to related pages
- [ ] Matches visual system (dark, diff, terminal)
- [ ] Passes QUALITY_GATE.md
