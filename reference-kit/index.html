Reference Kit

Templates and specifications an engineering or security team can use directly, whether or not it ever engages with Codokey. Each resource is plain text (Markdown or JSON), names the scorecard controls it supports, and states its limitations.

How the pieces fit

  1. Write an agent access policy entry per agent, then compare it with granted credentials (Reference Case B).
  2. Run the repository checklist before enabling an agent on a repository.
  3. Give approvers the PR review checklist; confirm deployment with the production checklist (Reference Case C).
  4. Configure logging to the audit evidence specification (Reference Case D); use the secrets-exposure review when something leaks.
  5. Record status in the scorecard and export it as your gap register.

Terms and status

Version 1.0.0. Not externally reviewed. Templates are vendor-neutral with platform-specific notes; they are not certification criteria or legal advice. Reuse terms have not yet been published — until a license is published, contact inquiry@codokey.com before redistributing.
