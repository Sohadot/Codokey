Position
Codokey is a sovereign digital asset.

Codokey.com is a privately held sovereign digital asset positioned around AI Code Access Governance, secrets security, agent permissions, and repository trust boundaries.

The asset comprises a reference model — not a deployed security product — including the Codokey Charter, Codokey Protocol v1.1, secrets boundary taxonomy, agent permission architecture, and governance scorecard. It is built for citation, adoption, extension, and institutional engagement.

Serious strategic acquisition, licensing, or institutional partnership inquiries may be considered.

Scope of Inquiry
What this asset represents.

Each component below can be inspected before any conversation. Nothing here asserts traction, revenue, adoption, or third-party endorsement — none has been recorded.

Original reference work. The six-layer protocol and layer specifications, the 32-control scorecard model with its gating methodology, four reproducible reference cases with a validator, the Reference Kit templates, and the Audit Evidence Specification.

Evidence architecture. A versioned Evidence Register separating externally supported claims from Codokey synthesis and Codokey doctrine.

Brand and domain. The Codokey name and codokey.com. The phrase "AI Code Access Governance" and the underlying security principles (least privilege, separation of duties, audit logging) are not claimed as exclusive property.

Provenance and maintenance. Full Git history, decision log, automated tests, and a static architecture with no runtime dependencies. See IP_AND_PROVENANCE.md in the repository.

Codokey does not represent a working security tool, SaaS product, or certification authority. Inquiries should be framed around reference model adoption, brand licensing, content acquisition, or strategic partnership — not product procurement.
