# Buyer Logic

Strategic relevance of the Codokey reference model across five buyer categories.

## Category 01 — AI Coding Platforms

Copilot, Cursor, Claude Code, and emerging agent platforms need a vendor-neutral governance language their enterprise customers can cite. Codokey provides the reference model — charter, protocol, agent permission taxonomy — without requiring any single vendor to own the standard.

**Engagement modes:** Reference adoption, co-branding, protocol extension, enterprise governance packaging.

## Category 02 — DevSecOps Companies

Pipeline security, SAST, and CI/CD gate vendors operate downstream of the governance gap. Codokey defines the upstream question: what can the agent access before code enters the pipeline?

**Protocol mapping:**
- Secret scanning → Key Exposure (Layer 02)
- Branch protection → Review Boundary (Layer 04)
- Deployment gates → Deployment Control (Layer 05)
- Audit logging → Audit Memory (Layer 06)

**Engagement modes:** Control mapping, scorecard integration, reference documentation licensing.

## Category 03 — Secrets Management Companies

Vault and secrets manager vendors protect secrets in storage. The AI agent governance question is about read context during IDE sessions. Codokey's secrets boundary defines eight credential classes and the rule that governance must precede agent sessions.

**Engagement modes:** Boundary definition partnership, agent-side governance vocabulary, enterprise policy templates.

## Category 04 — Git & Developer Platforms

GitHub, GitLab, and Bitbucket are the repository trust boundary layer. AI agents create new authority surfaces that existing permission models were not designed for.

**Engagement modes:** Agent permission architecture reference, forbidden zones framework, platform governance extension.

## Category 05 — AI Governance & Compliance Teams

Enterprise compliance, risk, and AI governance functions need definitional infrastructure — not another SaaS dashboard. The Charter, Protocol, and Scorecard provide audit-ready reference documentation.

**Engagement modes:** Policy citation, control mapping, self-assessment baseline, training material licensing.

## Asset Positioning Summary

Codokey is reference infrastructure — not product marketing. Strategic value lies in:

1. **Category definition** — AI Code Access Governance as a named discipline
2. **Definitional vocabulary** — code-key boundary, agent authority surface, audit memory
3. **Assessment framework** — 32-check scorecard aligned to six protocol layers
4. **Brand and domain** — codokey.com as sovereign digital asset
5. **Documentation corpus** — charter, protocol, buyer brief, content standards
