# Codokey

**Sovereign reference infrastructure for AI Code Access Governance.**

Codokey.com is a static, GitHub Pages–compatible strategic digital asset. It defines the access boundary between AI agents, codebases, secrets, and production authority — as a reference model, not a deployed security product.

## Deploy

Static site — no build step required.

1. Push to GitHub
2. Enable GitHub Pages (source: main branch, root `/`)
3. Optional: configure `CNAME` for `codokey.com`

## Positioning

Codokey is **not** a working security product unless an actual tool exists. It is:

- A reference model
- A charter and protocol
- A self-assessment scorecard
- A strategic digital asset
- Future-ready governance infrastructure
