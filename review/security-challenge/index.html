01 / 04 · CASE A

Agent access to secrets

Repository access is not the same thing as credential access. Whether an agent can read a secret depends on where the secret lives and on the boundary that enforces exclusion — not on whether the agent was "given the repo".

02 / 04 · CASE B

Excessive agent authority

An agent's authority should be derived from its task. Comparing what the task requires with what the credential grants turns "least privilege" from a slogan into a diff.
