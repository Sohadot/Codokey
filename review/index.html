Open Review

No independent review of Codokey has taken place yet. This page provides what a reviewer needs to evaluate the protocol, the scorecard model, the evidence register, and the reference cases — and a structured way to report what is wrong. Reviews received will be listed in the review log only with the reviewer's permission.

What to challenge

ArtifactQuestions for a reviewer
Protocol v1.1Are the six boundaries the right ones? What failure scenario falls between layers?
Scorecard model v2.0.0Are severities and forbidden-zone gates defensible? Is "more than half of critical controls" the right C threshold? Can an unsafe organization score well?
Evidence Register v1.0.0Is any passage misquoted, outdated, or stretched beyond what it supports? Is any claim in the wrong class?
Reference CasesConstruct an input the validator wrongly passes (false negative) or wrongly fails (false positive).
Reference KitCould a team adopt the templates as written? What is missing?

Reproduce in two minutes

node --test tests/*.test.mjs         # Node 18+, no dependencies
node tools/build.mjs --check         # generated pages match their sources

Rubric

Classify each finding by type — false negative, false positive, missing control, severity/gate, evidence defect, claim-class error, usability — and rate impact (3 material, 2 significant, 1 minor) and confidence (high/medium/low). Full rubric: RUBRIC.md. Template: FEEDBACK_TEMPLATE.md. Package overview: README.md.

Send findings

Open an issue in the project repository using the "Review finding" form, or email inquiry@codokey.com. Never include real secrets or confidential configuration.
