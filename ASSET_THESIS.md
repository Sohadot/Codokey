## Foundational Shift

AI coding did not merely change who writes software. **It changed where authority begins.**

Software used to be governed by who wrote the code. In the era of AI coding agents, it must be governed by **what the code and the agent can access, expose, change, and release**.

Most AI coding workflows define agent permissions after the agent is already inside the codebase. The boundary between what an agent can see, modify, encounter as secrets, and move toward production — the **agent authority surface** — is often undefined.

That is the governance gap. AI Code Access Governance is the discipline that closes it.
