# Asset Thesis

## Core Thesis

Codokey is the sovereign reference model for defining the access boundary between AI agents, codebases, secrets, and production authority.

## The Governance Gap

Software used to be governed by who wrote the code. In the era of AI coding agents, it must be governed by **what the code can access**.

Most AI coding workflows define agent permissions after the agent is already inside the codebase. The boundary between what an agent can see, modify, encounter as secrets, and move toward production — the **agent authority surface** — is often undefined.

That is the governance gap.

## What Codokey Is

- A **reference model** for AI Code Access Governance
- A **charter** establishing founding principles
- A **protocol** with six definitional layers
- A **scorecard** for self-assessment (not certification)
- A **strategic digital asset** positioned for institutional engagement

## What Codokey Is Not

- Not a deployed security product
- Not a SaaS platform
- Not a certification authority
- Not vendor-specific tooling
- Not a marketing funnel with fake product claims

## Strategic Value

The definitional layer is the most durable asset in emerging governance categories. Before platforms build controls, enterprises need language. Before auditors write policies, compliance teams need frameworks. Before incidents occur, engineering teams need boundaries.

Codokey provides that definitional layer — vendor-agnostic, citation-ready, and built for adoption.
