# Codokey Reference Kit v1.0.0

Practical, vendor-neutral resources for applying the Codokey Protocol. Each file states its purpose, the scorecard controls it supports, and its limitations.

| Resource | Use it to |
|---|---|
| [Agent access policy](agent-access-policy.md) + [JSON example](agent-access-policy.example.json) | Declare each agent's scope before it runs |
| [Repository access-boundary checklist](repository-access-boundary-checklist.md) | Verify a repository before enabling an agent |
| [Secrets-exposure review](secrets-exposure-review.md) | Contain and analyze a possible secret exposure |
| [AI-generated PR review checklist](ai-pr-review-checklist.md) | Review agent pull requests |
| [Production authorization checklist](production-authorization-checklist.md) | Confirm the human gate before production |
| [Audit evidence specification](audit-evidence-specification.md) | Define the records needed to reconstruct a session |
| [Control catalog (JSON)](../reference/controls.json) · [Protocol–control map (CSV)](../reference/protocol-control-map.csv) | Import the 32 controls into your own tracker |
